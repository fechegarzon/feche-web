Method

I govern agents like a new hire who was handed too many keys.

The job is to take most of them back. Rules that matter live in code, below the model, where a prompt can't negotiate them.

The autonomy ladder

An agent earns the right to act alone with evidence, not enthusiasm.

  1. 01Reads

    Anonymized contracts, never other people's inboxes.

  2. 02Suggests

    Proposes who to contact; never guesses an address.

  3. 03Drafts

    The agent writes; a person sends.

  4. 04Acts with brakes

    With brakes and the owner's sign-off: if nobody switches it on, nothing goes out.

  5. 05Autonomous

    Only with evidence: a long record approved unchanged and zero incidents.

01

If a rule matters, enforce it below the model.

02

Verify the side effect, not the return code.

03

Monitoring must not depend on the thing it monitors.

04

The model explains; the code decides.

Notes from production

What broke, and the rule that stayed.

Fifteen real incidents, each with the rule it left behind. It's what nobody shows in a demo, and what helps most when you're about to put AI to work. Headlines here; the detail, in conversation.

Book a call for all 15 lessons
  1. #01

    The bot answered inside a WhatsApp group

    A prompt is a request; the transport layer is a wall.

  2. #03

    A dashboard sat at zero for two weeks, with no error

    A dashboard showing zero should be an error, not a number.

  3. #05

    The job said “10 emails sent”. None were.

    Verify the side effect, not the return code.

  4. #12

    The model recommended a lender we don't work with

    Anything that can create a commercial promise is computed, not generated.

  5. #13

    The voice agent heard a language nobody was speaking

    Voice agents fail in the room, not in the lab.

  6. #14

    We almost paid bonuses on a number that was mostly noise

    Before a metric moves money, measure how reliable it is.
